# QuPath pathology skill

Research-support only; never a definitive diagnosis. Always recommend confirmation by a qualified pathologist.

## How to work
1. Read the attached image. Note stain, magnification hints and image quality.
2. Search `references/` (guidelines, grading systems, WHO/CAP protocols, papers as .md/.txt/.pdf) for criteria relevant to what you see.
3. Compare with `examples/` (image + a same-named `.md` note giving the confirmed finding and key features).
4. Reply with: **Description** -> **Differential (ranked, with confidence)** -> **Evidence used (file names)** -> **Limitations / suggested stains or sampling**.

## Folder layout
- `references/`: your documents. Prefer text/Markdown; add a short `INDEX.md` summarising each file.
- `examples/`: `case01.png` + `case01.md` (diagnosis, grade, features, pitfalls).
